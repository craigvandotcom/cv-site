The innovation loop

How I turn recurring friction into tools people actually use — and keep compounding each pass. Hover any step for a real example from GenAI Auto Kit.

  1. 1
    Find pain

    Start with repeated friction in real workflows.

    Example For GenAI Auto Kit, the signal came from repetitive support and operations tasks: summaries, merchant replies, investigation prompts, classification, request analysis, and log review.
  2. 2
    Build messy

    Prototype quickly enough to test usefulness.

    Example The first versions were built to automate my own workflow: simple highlight-and-trigger transforms, fast prompt iteration, and enough structure to learn what worked.
  3. 3
    Test with users

    Demo, gather feedback, and discover use cases.

    Example I demoed the workflows to Support, got strong feedback, and discovered more use cases once people saw how the framework could fit into day-to-day work.
  4. 4
    Harden + scale

    Make it resilient, repeatable, and distributable.

    Example The work moved toward polished UX, more resilient flows, multi-step synced workflows, and working with IS toward distribution through Managed Software Center.

↻ …then repeat — each pass compounds on the last.
